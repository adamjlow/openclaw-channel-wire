# Security policy

This plugin handles decrypted end-to-end encrypted messages and the credentials of a Wire app, so
security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's private vulnerability reporting on this
repository (**Security** tab, **Report a vulnerability**), and include steps to reproduce and the
version affected. You should get an acknowledgement within a few working days.

Vulnerabilities in the Wire SDK itself should be reported to
[wireapp/wire-apps-js-sdk](https://github.com/wireapp/wire-apps-js-sdk). Vulnerabilities in
OpenClaw should be reported to [openclaw/openclaw](https://github.com/openclaw/openclaw).

## Supported versions

Security fixes go into the latest release.
